📝 Descrição do Projeto
Este projeto consiste no desenvolvimento de um aplicativo interativo e automatizado em Microsoft Excel para auxiliar no gerenciamento e organização da Declaração do Imposto de Renda. A solução foi projetada para oferecer uma navegação intuitiva, formulários estruturados para entrada de dados do contribuinte e telas dedicadas para controle financeiro, de informes e anotações.

🛠️ Estrutura e Funcionalidades do Aplicativo
O aplicativo foi construído e organizado através dos seguintes módulos e telas:

Navegação e Interface (Menu Principal):

Menu e Menu Itens: Painel central de navegação que permite ao usuário alternar facilmente entre as diferentes telas e seções do sistema.

Entrada e Validação de Dados:

Formulário Titular: Tela dedicada para o cadastramento e organização dos dados pessoais e cadastrais do titular da declaração.

Formatações Personalizadas: Aplicação de regras visuais e formatação de células para garantir a correta exibição de valores monetários, documentos (CPF) e datas, melhorando a usabilidade.

Módulos de Controle e Consulta:

Tela de Informes: Área voltada para a inclusão e conferência dos dados de rendimentos, deduções e comprovantes necessários para o imposto.

Tela de Notas: Espaço complementar para anotações, lembretes e observações importantes sobre o preenchimento ou pendências de documentos.

Lógica e Automação:

Funções e Fórmulas Personalizadas: Implementação de fórmulas do Excel para cálculo, automatização no cruzamento de informações e consistência dos dados apresentados.

🚀 Tecnologias e Recursos Utilizados
Microsoft Excel

Fórmulas e Funções do Excel (Cálculos automáticos e lógica de dados)

Design de Interface no Excel (Criação de menus, botões e navegação)

Formatação Condicional e Personalizada

🎯 Objetivo Profissional
Demonstrar a aplicação prática de conceitos de lógica de dados, organização de planilhas, design de interface funcional (UI/UX no Excel) e automação de processos para a resolução de problemas financeiros do dia a dia.
